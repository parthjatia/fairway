# Demo video script (about 2:50): a live launch

Setup: run `pnpm demo` and open http://localhost:3000. Use dark mode and a 1440×900 browser window. Clear the site's localStorage first, so the wizard starts clean. The **"Simulated data"** badge must be visible in the corner: say it is simulated within the first 20 seconds. In mock mode a launch runs in the browser on the same engine as the backtest. Playback speeds are relative: **1×** plays the 15-minute launch in about 22 s, and 2.5× (the default) in about 9 s.

## Shot notes

- **"33 times more" at ~slot 20:** in the panel the sniper pays the TOXIC fee and Rita the RETAIL fee at the current slot (at slot 0: 1000 vs 30 bps, so $20 vs $0.60 on $200). Read the number off the screen if you pause elsewhere.
- **Backup launch:** if the wizard misbehaves, open `/launch/frog` (a preset demo launch) and continue from 1:05.
- **Live-mode variant** (only if `pnpm demo:local` works on the recording machine): set `NEXT_PUBLIC_MODE=live`, connect a local wallet, and create the launch for real. `/launch/<mint>` then shows the onchain fee per tier and `SwapExecuted` events. The mock replay is the default for the video.
