- 2026-11-19 — M16 launch fee: per-pool `PoolLaunch { launch_slot, window_slots, curve(start/end per tier), twap_scoring }` set by `configure_launch` (pool creator or admin, only before the first swap). After the window the normal `Config.fee_bps` apply, so RETAIL goes from 5 bps (end of the curve) back to the configured retail fee. The spec says "normal tier fees apply" and we followed it literally. Config defaults: TOXIC 1000→80, STANDARD 300→30, RETAIL 30→5, window 750 slots (~5 min), launch fee 0.05 SOL to the treasury (admin-configured launches are exempt).

- 2026-11-19 — M16 TWAP reference price: on TWAP pools, PendingTrade.exec_price stores the POST-trade pool price, not the execution price. - 2026-11-19 — M16 TWAP storage: 64 observations ≥ 8 slots apart, each a u64 slot plus a u128 cum (≈1.5 KB in Pool). SetPoolOracle's Pool is now boxed for the same reason. Window: 25 slots ending at the trade slot + 75 (`Config.launch.twap_window_slots`, must be ≤ markout_slots). `settle_markout` ignores its oracle account on TWAP pools (the SDK passes the pool).

- 2026-11-19 — M16 step 11: fundings are extracted by the same Stream L filter (no second Stream). A funding is a System/ComputeBudget-only tx that sends ≥ 0.05 SOL to an account with 0 lamports before. A bundle is ≥ 2 early buyers (≤ 25 slots) of one launch funded by one source within 1,500 slots before the launch (at the latest in the buy slot). A known bundler has ≥ 2 bundled launches, and its later fresh wallets are flagged pre-emptively. Flags only raise tiers: at least STANDARD, TOXIC if the funder is a known bundler or a TOXIC sniper.
